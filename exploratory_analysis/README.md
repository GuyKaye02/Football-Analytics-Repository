# Exploratory Football Analysis

This directory contains exploratory and descriptive analyses conducted to investigate high-level questions in football using public data (e.g. StatsBomb, FBref, Transfermarkt).

These analyses are intentionally lightweight and visualization-driven, and are designed to:
- Explore hypotheses prior to formal modeling
- Build intuition around football dynamics
- Inform later probabilistic and machine learning projects

They are **not** intended as production-grade models, but as analytical groundwork and communication exercises.

---

## Example Questions Explored

### Transfer Market Structure
- How do median transfer fees vary by position across the Big 5 leagues?
- Which positions exhibit the highest variance and tail risk?

### Squad Composition
- How does average squad age differ across leagues?
- Is there evidence of a relationship between squad age and performance?

### Team Performance Trends
- Rolling expected goals (xG) trends across seasons
- Visual inspection of structural breaks (e.g. managerial changes)

### Spatial & Event-Based Visuals
- Player touchmaps
- Basic spatial density plots
