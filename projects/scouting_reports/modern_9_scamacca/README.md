# The Importance of the Modern #9 — Tactical Analysis

This project examines the evolving role of the modern centre-forward through video-based tactical analysis and telestration.

The focus is on movement, spatial occupation, and off-ball contribution rather than goal output alone.  
This work predates my current machine-learning-focused projects and reflects a traditional scouting and tactical analysis approach.
